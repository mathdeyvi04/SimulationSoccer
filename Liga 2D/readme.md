# Descrição

Em face das múltiplas competições disponíveis nesta categoria,
fez-se necessário uma ação de desenvolvimento repentina para que
a RoboIME possa se destacar.

Ao contrário da categoria 3D, esta categoria 2D é mais fácil em termos 
de desenvolvimento e possui mais competições disponíveis.

Alguns arquivos e sites para lhe ajudar a compreender melhor a categoria:

- [Sobre_Setup.md](Sobre_Setup.md)
- [Wikipedia](https://en.wikipedia.org/wiki/RoboCup_2D_Soccer_Simulation_League)
